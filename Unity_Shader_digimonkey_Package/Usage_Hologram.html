Hologram Object

導入と基本操作 投影とグラデーション 設定項目 困ったとき

導入と基本操作

  1. HologramObject.shaderをAssets内、HologramObjectShaderGUI.csをEditorフォルダーへ配置します。
  2. Materialを作成し、ShaderをDiGiMonkey/Hologram Objectにして対象Rendererへ割り当てます。Create Materialsで作成したM_HologramObjectも使えます。
  3. Hologram ColorとEmission Intensityを調整します。形を確認しやすくするにはGlitch Strength、Noise Amount、Flicker Amountを一度0にします。
  4. Gradient Axisを選び、自動フィットでモデルの範囲に合わせます。

投影とグラデーション

Texture Projection (Model Space)

Mask / Detail Textureは画像のRGB色をそのまま表示せず、輝度×アルファを発光・透明度の強弱へ使います。黒い部分も完全な透明にはなりません。

  • Original UV：モデルのUV。初期設定です。
  • Planar：Front (XY)、Side (ZY)、Top (XZ)の平面投影。
  • Box (Triplanar)：3方向の画像を法線でブレンド。文字やロゴは境界で混ざる場合があります。
  • Cylindrical (Y Axis)：Y軸の周囲へ一周。中央は＋Z、継ぎ目は−Z。上下面は歪みます。
  • Spherical (Y Axis)：経度・緯度で球面投影。中央は＋Z、継ぎ目は−Z。極には歪みます。

Projection Center／Sizeは各RendererのローカルXYZです。原点が足元、高さ2ならCenter Y＝1、Size Y＝2から試します。Tilingで画像を拡大縮小、Offsetで画像の参照位置を移動します。Tiling＝2で細かく、0.5で大きく表示。球面のXYZサイズを同じ倍率で変えても角度は変わらないため、画像の拡大にはTilingを使います。

平面投影は裏側にも同じ画像が出ます。継ぎ目には左右がつながる画像とWrap Mode＝Repeatが適しています。SkinnedMeshRendererでは変形後の座標から投影するためポーズで柄が変わる場合があります。

Gradient Axisと自動フィット

軸は各Rendererのローカル座標です。Local Y／Local Zが必ずモデルの上下になるとは限りません。上下に合うLocal X／Y／Zを選び、Hierarchyで対象を選択して Tools > Hologram URP > Fit Selected Object Vertical Gradient を実行します。選択オブジェクトのRenderer、なければ最初に見つかった子Rendererの範囲を使います。子Rendererすべてを個別にフィットする機能ではありません。

Gradient Minimum / Maximumは小さい座標・大きい座標です。向きが逆ならInvert Top/Bottomを使います。自動フィットは共有Materialを書き換えるので、同じMaterialを使う別モデルにも影響します。Beam系のUVモードではローカル範囲を使わず、自動フィットはスキップされます。

既存Materialは以前のY／Z、またはUV／Zの選択を維持します。内部のLegacy値は互換用で、通常のInspectorでは実際の軸が表示されます。

発光のにじみはBloomで作ります。Tools > Hologram URP > Setup Bloom and Post Processing で設定できます。この操作はGlobal Volume、Camera、URP AssetのHDR設定を変更します。セットアップツールの説明も確認してください。

Hologram Beam

導入と基本操作 縁と上下フェードの調整 設定項目 困ったとき

導入と基本操作

  1. HologramBeam.shaderをAssets内、HologramGradientShaderGUI.csをEditorフォルダーへ配置します。
  2. DiGiMonkey/Hologram BeamのMaterialを円錐などのMeshRendererへ割り当てます。
  3. 簡単に試すにはTools > Hologram URP > Create Demo Objectsを実行します。
  4. Beam Color、Opacity、Emission Intensityを調整し、Edge Powerで縁の太さを仕上げます。

縁と上下フェードの調整

視線に対して縁になる部分ほど光る方式です。中央の塗りや放射状ラインを足すには、別のBeam Fill Radialを重ねます。

UVモードではUV.y＝0～1を上下範囲に使います。元のUVが不適切ならLocal X／Y／Zを選び、自動フィットを実行してください。Bottom Fade WidthとTop Fade Widthを大きくすると、それぞれの端が広く透明になります。

このShaderにはTexture欄や平面・BOX・筒状・球面のTexture投影機能はありません。走査線は選択したグラデーション座標、ノイズはワールドXZを使います。

Gradient Axisと自動フィット

軸は各Rendererのローカル座標です。Local Y／Local Zが必ずモデルの上下になるとは限りません。上下に合うLocal X／Y／Zを選び、Hierarchyで対象を選択して Tools > Hologram URP > Fit Selected Object Vertical Gradient を実行します。選択オブジェクトのRenderer、なければ最初に見つかった子Rendererの範囲を使います。子Rendererすべてを個別にフィットする機能ではありません。

Hologram Beam Fill Radial

導入と基本操作 中央・放射ライン・上下範囲 設定項目 困ったとき

導入と基本操作

  1. HologramBeamFillRadial.shaderと、Editorフォルダー内のHologramGradientShaderGUI.csを導入します。
  2. MaterialのShaderをDiGiMonkey/Hologram Beam Fill Radialにして円錐へ割り当てます。
  3. 既存Beamを選んでTools > Hologram URP > Add Fill Radial To Selected Beamを実行すると、同じMesh・Transformの補助オブジェクトが同じ親の下に追加されます。
  4. 中央の塗りはInterior Fill Intensity、放射線はRadial Ray Intensityで調整します。

中央・放射ライン・上下範囲

Interior Center Powerを上げると、視線を向く中央側へ発光が集まります。放射線だけを使うならInterior Fill Intensity＝0、中央だけならRadial Ray Intensity＝0にします。

Radial Ray CountはUV.xを使います。モデルの周囲にUV.x＝0～1が一周する円錐などが適しています。Gradient Axisをローカル軸へ変更しても、放射線の位置はUV.xのままです。Texture投影機能はありません。

Ray Widthで太さ、Softnessでぼかし、Rotation Speedで模様の動きを調整します。これはUV上の位相移動で、モデルそのものの回転ではありません。

Gradient Axisと自動フィット

軸は各Rendererのローカル座標です。Local Y／Local Zが必ずモデルの上下になるとは限りません。上下に合うLocal X／Y／Zを選び、Hierarchyで対象を選択して Tools > Hologram URP > Fit Selected Object Vertical Gradient を実行します。選択オブジェクトのRenderer、なければ最初に見つかった子Rendererの範囲を使います。子Rendererすべてを個別にフィットする機能ではありません。

Hologram Setup Tool

導入 メニュー一覧 操作例と確認 困ったとき

導入

HologramSetupTool.csをEditorフォルダーへ配置し、関連するShaderとGUIを導入します。UnityのTools > Hologram URPから実行します。生成先はAssets/HologramURP内のMaterials／Meshes／Settingsです。

メニュー一覧

メニュー動作・影響
Create MaterialsObject、Beam、Beam Fill Radial、XRay Mask、XRay Outlineの5つのMaterialを作成。既存の同じパスのMaterialは上書きしません。SP ToonやBox Clipは作成しません。
Create Demo Objects球体・縁用円錐・中央／放射用円錐を作成し、Bloomも設定。繰り返すと新しいデモが追加されます。
Setup Bloom and Post ProcessingGlobal Volumeを作成または再利用。Bloom Intensity＝1.6、Threshold＝0.7、Scatter＝0.7へ設定。CameraのHDR／Post Processing／Volume Layer Maskと、現在のURP AssetのHDRも変更します。既存Profileの該当値も更新します。
Fit Selected Object Vertical Gradient選択したRenderer、なければ最初の子Rendererのローカル範囲を、選択軸のMinimum／Maximumへ設定。共有Materialを保存します。Beam系のUVモードはスキップ。
Add Fill Radial To Selected Beam選択オブジェクトと同じ親の下に補助オブジェクトを追加。元のMeshを共有し、ローカルPosition／Rotation／Scaleをコピーします。対象にはMeshFilterとMeshが必要です。再実行で追加されます。

操作例と確認

  1. Create Demo Objectsで各ホログラムの役割を確認します。
  2. 自分のモデルへM_HologramObjectを割り当てます。
  3. MaterialのGradient Axisをモデルの高さに合わせます。
  4. モデルを選びFit Selected Object Vertical Gradientを実行します。
  5. 壁越し表現の追加・解除はXray説明書を参照してください。

一部のScene操作とMaterial変更はUndoに対応しますが、アセット作成・保存やBloom設定のすべてが1回のUndoで戻るわけではありません。Sceneとアセットを確認して保存してください。

  • フェードが前後にかかる：モデルのローカル軸を確認し、上下に合う軸を選びます。Zが必ず上下ではありません。
