1. 導入と最初の操作

UnityのUniversal Render Pipeline（URP）を使用するプロジェクト向けです。Built-in／HDRP用ではありません。以下は同梱ファイルの実装をもとにした説明です。

  1. SPToonURP.shader と SPToonURPShaderGUI.cs をプロジェクトのAssets内へ配置します。GUIスクリプトはEditorフォルダーへ配置してください。既に導入済みなら同名ファイルを重複させないでください。
  2. コンパイル完了後、ProjectでMaterialを作成し、Shaderを DiGiMonkey/SP Toon URP にします。
  3. Materialを対象Rendererへ割り当て、Inspectorの Toon Gradation でBaseと各Toon段階を設定します。
  4. Surface Mode を用途に合わせて選びます。新規Materialでは必要に応じて別のモードへ一度切り替えて戻し、描画設定を反映させてください。
  5. まずHDR EnabledをOFFのままLight Positionで陰影を確認し、その後、線や質感を追加すると調整しやすくなります。

このシェーダーはMaterialのInspectorから設定します。「Tools ＞ Hologram URP」はホログラム／Xray用の補助ツールです。

2. Lighting・Toon Gradation

項目動作と調整
HDR Enabled
初期値 OFF		OFF：Light Positionとモデルの位置から光の方向を計算します。ON：Unityのライト方向・強度・距離減衰・影を陰影判定に使います。複数ライトは最も強い陰影評価を採用します。ライトの色をそのままMaterial色に乗算する方式ではありません。
HDR Ambient Strength
0～5 / 初期値0		HDR EnabledがONのとき、環境光の明るさを陰影評価へ加算します。大きすぎると暗い段階が減ります。HDR画像を直接割り当てる欄ではありません。
Light Position
初期値 (10,10,10)		手動の光源位置（ワールド座標）。HDR EnabledがOFFのときに有効です。Numeric入力と各軸の−20～20のスライダーで調整します。
Toon Param 2～7
−1～1		各色へ切り替わる陰影のしきい値。陰影評価がしきい値より小さい領域に、その段階の色が現れます。2→7の順で重ねるため、通常はParam 2 ≥ 3 ≥ 4 ≥ 5 ≥ 6 ≥ 7の順に設定します。
Toon Blur
0～5 / 初期値0		段階の境界をぼかします。0に近いほど硬い境界、大きいほど滑らかなグラデーションになります。
Base Color / Texture
Toon Color / Texture 2～7		各段階は「TextureのRGB × ColorのRGB」で独立して着色します。Base Textureだけでは影段階に同じ柄は出ません。全段階で柄を保持したい場合は、同じTextureを各Toon Textureにも設定します。白いTextureならColorがそのまま使われます。

初期しきい値はParam 2＝0、Param 3＝−0.5、Param 4～7＝−1です。−1は厳密な無効化スイッチではなく、陰影評価の最小値付近では影響することがあります。使わない段階は直前と同じ色・Textureにすると見た目を揃えられます。

3. Hull Outline・Outline・Inline

Hull Outline はメッシュを法線方向へ広げて描く外側の輪郭です。Outline は視線と法線の角度を使って表面の縁を着色します。Inline はCurvature Mapを使う内部線です。

項目動作と調整
Use Hull Outline / Width外側輪郭のON/OFF。Widthは0～0.1、初期値0.003。メッシュを広げる量なのでモデルの大きさやスケールにより見え方が変わります。
Hull Outline Color / Texture輪郭の色とTexture。白いTextureなら指定色で描きます。
Noise Strength / ScaleHull輪郭の揺らぎ。Strengthは0～5（0で揺らぎなし）、Scaleは0.1～200。少しずつ増やして確認します。
Use Outline / Reverse Outline表面の縁の着色を有効化します。Reverseでマスクを反転し、縁以外の領域を着色します。
Outline Thickness / BlurThicknessは0～1（初期値0.6）。大きいほど着色範囲が広がります。Blurは0～5。これはピクセル単位の線幅ではありません。
Outline Color / Texture表面の縁に使う色とTexture。
Inline Thickness / BlurCurvature MapのR値をしきい値で判定します。Thicknessは0～1（初期値0.14）、Blurは0～5。暗い領域ほど内部線になります。
Inline Curvature Map / Invert Curvature内部線の位置を指定するマップ。Invertで白黒判定を反転します。初期の白いマップでは通常、内部線はほぼ出ません。メッシュから曲率を自動生成する機能ではありません。
Inline Color / Texture / Inline on Top内部線の色・Texture。Inline on Topは0～1で、0ならOutlineを後に、1ならInlineを後に重ねます。中間値は両方の合成結果を混ぜます。

4. Normal・AO・Rim・Thickness・MatCap

項目動作と調整
Normal Map / Strength法線マップで陰影と縁の見え方を変えます。UnityのTexture Import SettingsでNormal mapとして設定してください。Strengthは−5～5、初期値1。0なら凹凸の影響を抑えます。
AO Map / Strength / ColorAO MapのR値を使い、暗い領域へAO Colorの色味を乗算します。Strengthは0～5、初期値1。まず0～1で調整すると扱いやすく、1超では計算が外挿されるため強く変化します。白いマップは通常、影響なしです。
Use Rim Light / Strength / Sharpness / Color視線に対して縁になる部分へ色を加算します。光側ほど強くなります。Strengthは0～20、Sharpnessは0～50。Sharpnessを上げるほど細い縁に集まります。
Use Thickness / Map / Strength / Color逆光側の縁へ色を加算し、透過光のような表現を作ります。MapのR値は白ほど効果が強く、黒ほど弱くなります。Strengthは0～10。実際のメッシュ厚さを自動計測する方式ではありません。
Use MatCap / Texture / Strength / Blend Mode法線と視線方向からMatCapのUVを求めます。Inspector表記は「World Space Normals」ですが視線にも依存します。Strengthは0～10。Addは加算、Multiplyは「元の色 × (1＋MatCap×Strength)」で、一般的な単純乗算とは異なります。

AO → Rim → Thickness → MatCap → Outline／Inlineの順で合成します。後から重ねる線の色が質感効果を覆うことがあります。

5. Surface・透過と切り抜き

Surface Mode表示描画設定
Opaque不透明・片面深度書込ON / Queue 2000
Cutout切り抜き用・片面深度書込ON / Queue 2450
Transparent半透明・片面深度書込OFF / Queue 3000
Cutout Both Sides切り抜き用・両面深度書込ON / Queue 2450
Transparent Both Sides半透明・両面深度書込OFF / Queue 3000
  • Opacity Map のR値を透明度に使います。白＝不透明、黒＝透明。Base TextureのアルファやBase Colorのアルファは本体の透明度には使いません。
  • Invert Opacity Map で白黒を反転します。
  • Opacity は0～1、Transparent系で有効です。Opacity Mapの値へ乗算します。
  • Cutout系では Alpha Clip (0/1) もONにしてください。モード選択だけではAlpha Clipは自動ONになりません。
  • Alpha Clip Threshold は0～1、初期値1。マップ値がしきい値未満の部分を捨てます。まず0.5程度から調整してください。

Alpha Clipは実装上、スイッチがONなら他のモードでも処理されます。通常のOpaque／Transparentへ戻すときはAlpha ClipもOFFにしてください。半透明の重なりは描画順により見え方が変わります。

6. 設定のコピーと貼り付け

  1. 元のMaterialを1つ選び、Copy Values & Colors を押します。
  2. 同じShaderを使用する貼り付け先Materialを選び、Paste Values & Colors を押します。貼り付け先は複数選択にも対応します。

数値、色、ベクトル、モード、TextureのTiling／Offset、Shader keywords、Render Queueをコピーします。Textureアセットの割り当ては貼り付け先を保持します。 OSのクリップボードを使うため、別の内容をコピーすると貼り付けできなくなります。貼り付けはUndoに対応します。

7. 調整の出発点

硬いトゥーン陰影

HDR Enabled＝OFF、Toon Blur＝0、Param 2＝0、Param 3＝−0.5から始めます。Base・Toon 2・Toon 3を明るい順の色にし、他の段階はToon 3と同じ色・Textureに揃えます。Light Positionを動かして境界を確認します。

黒い外側輪郭を主役にする

Use Hull Outline＝ON、Color＝黒、Width＝0.003を出発点にし、Use Outline＝OFFで外側の線を確認します。モデルのスケールに合わせてWidthを調整してください。

内部線を入れる

線を出したい部分を黒くしたCurvature Mapを用意し、Inline Thickness＝0.14、Blur＝0から調整します。白黒の意図が逆ならInvert CurvatureをONにします。

髪・葉などを切り抜く

Surface Mode＝Cutout Both Sides、Alpha Clip＝ON、Threshold＝0.5。Opacity Mapに白黒マスクを設定します。

半透明にする

Surface Mode＝Transparent（両面が必要ならTransparent Both Sides）、Alpha Clip＝OFF、Opacity＝0.5から確認します。マスクが不要ならOpacity Mapは白を使います。

これらは実装に基づく調整例です。モデル・ライト・URP設定によって結果は変わります。

8. 困ったとき

症状確認するところ
ピンクになるURPを使用しているか、ConsoleにShaderのエラーがないか確認します。
専用Inspectorが出ないSPToonURPShaderGUI.csの導入とConsoleのC#コンパイルエラーを確認します。GUIはDiGiMonkey.SPToonURPShaderGUIです。
Unityのライトを動かしても変わらないHDR EnabledをONにします。追加ライトはURP側の有効設定も確認してください。
明るすぎる／段階が見えないHDR Ambient Strength、Toon Blur、しきい値の順序、Rim／Thickness／MatCapの強度を確認します。
影にTextureの柄が出ない各Toon Textureにも必要なTextureを設定します。
内部線が出ない／全面に出るCurvature MapのR値、Invert Curvature、Inline Thicknessを確認します。
透明にならない／切り抜けないSurface Mode、Opacity MapのR値、Opacity、Alpha Clip、Thresholdを確認します。Baseのアルファでは制御しません。
輪郭が太すぎる／着色範囲が広すぎる外側の線ならHull Width、表面の着色ならOutline Thicknessを下げます。
