# SP Toon URP Outline Paint

**Outline Paint Ver. 1.9.4**（2026-11-13）

この番号は、実プロジェクトのOutline Paint機能を管理するためのものです。配布元のSP Toon URPパッケージ番号とは別に管理します。構成は `SPToonURP.shader` と `SPToonOutlinePainter.cs` の2ファイルです。

既存のHull OutlineをSceneビューで直接ペイントし、部分ごとの太さや消去を調整できます。片面メッシュの外周線と、髪の手前に眉毛の輪郭線だけを重ねる設定にも対応します。

## 使い方

1. マテリアルの **Hull Outline (Inverted Hull) > このHull Outlineをペイント調整** を開きます。
2. 作業する部位にチェックを入れます。複数同時にONにできます。
3. 大きい **Sceneペイントを有効にする** ボタンをONにし、Sceneビューで黒いHull Outlineへ直接ブラシを当てます。
4. Scene / Prefabを通常どおり保存します。

## 顔サンプルをシーンに追加する

**Tools → DiGiMonkey → Create Face Sample** を実行すると、アクティブなシーンの原点に `SPToonFaceSample` を追加します。作成後はHierarchyでサンプルが選択され、Undoで取り消せます。

サンプルには髪の外周線、眉毛の輪郭線の前面表示、顔による遮蔽の設定が入っています。顔はUnityの標準Sphere、眉毛は標準Planeから作ります。髪は前側4枚、後ろ側3枚の標準Planeを重ねて作ります。眉毛にかかる長さの前髪で、髪に隠れる眉毛の塗りと、髪の上に出る眉毛の輪郭線を見比べられます。プロジェクト内のサンプルマテリアルを再利用し、見つからない場合は `Assets/SPToonFaceSample` に作成します。作成時に、プロジェクトで使用するURP Rendererへ必要な描画パスを追加します。生成済みマテリアルの影色がすべてグレーの場合は、ベース色に合わせて補正します。

## 親のPainterで子階層を制御する

親に **SP Toon Outline Painter** を付け、**子階層も対象にする** をONにします。チェックした子・孫以降に、親の片面外周線、髪マスク、眉毛の前面表示、顔の遮蔽を適用します。チェックを外すと親からの適用が止まります。

新しい顔サンプルでは `Hair` のPainter 1個で7枚のPlaneを制御します。既に子自身にPainterがある場合は、その子の個別設定とペイントが優先されます。既存のサンプルで親1個の構成を試す場合は、**Create Face Sample** で新しく生成してください。

## チェックした部位へ共通適用

**チェックは、設定と操作を反映する対象です。** 表示・面反転・内外の最大倍率・レイヤーの表示／固定／強さ／名前／追加／複製／削除／順序・範囲操作・ブラシ・初期化が、ONの全部位に反映されます。OFFの部位には反映しません。

右の「表示基準」は、設定欄にどの部位の値を表示するかを選ぶものです。操作対象を1部位へ限定するボタンではありません。複数部位の値が異なる表示設定には混在表示が出ます。

部位を追加でONにすると、既にチェックしている部位の表示・倍率・レイヤー設定を引き継ぎます。メッシュごとのペイント値はそのまま保持し、別メッシュの頂点データをコピーすることはありません。「全部ON」「全部OFF」も使用できます。チェックを外しても線やデータは消えません。

**Hull Outlineを表示** をONにすれば、チェックした全部位を再表示できます。独立した一括非表示ボタンはありません。

## ラインの操作はペイントと初期化

- **ペイント**：現在のHull Outlineへ補正を塗ります。別の線や描画オブジェクトは追加しません。
- **チェック部位のペイントを初期化**：ONの全部位で補正・消去を解除し、表示ON・通常の面方向に戻します。元のマテリアルのWidth・色・Texture・Noiseで描く線へ戻ります。

初期化はロックされたレイヤー内の補正も解除します。レイヤー構成・名前・表示／ロック・強さ・範囲マスク・ブラシ設定は残します。OFFの部位は変更しません。初期化も複数部位のペイントも、Undo1回でまとめて戻せます。

## ブラシ

ブラシの初期値は、半径0.1、強さ0.2、硬さ0.2です。作業対象マテリアルは「すべて」、塗る対象は「Hull Outline（見えている線）」です。

「今のWidthに対する倍率」は **1＝現在の線、0＝膨らみなし、負＝内側へ押し込み、1より大きい＝太くする** です。外側・内側の最大倍率は、マテリアルのWidthを基準にします。未ペイント部分は元の線を保持します。

中心100%、外周0%へ滑らかに減衰するソフトブラシです。半径（ワールド単位）・強さ・硬さを調整できます。

- **太さ**：目標の倍率へ近づけます。
- **線を消す**：ゼロ幅でも残る線を消します。
- **範囲マスク**：作業できる領域を塗ります。
- **調整を戻す**：そのレイヤーの調整を外して、下の結果や元の線を表示します。

「塗る対象」の初期値は **Hull Outline（見えている線）** です。表示と同じ膨らみ量で作る当たり判定を使い、線から元の頂点へ補正を反映します。消した線や内部へ押し込んだ線を戻す場合は **元の面（消した線の復元用）** に切り替えて塗ります。Altは視点操作、Escはペイント終了です。

## 片面メッシュに外周線を出す

1. 対象のメッシュのImport Settingsで **Read/Write** を有効にします。
2. 対象を選び、Inspectorの **SP Toon Outline Painter → 片面板の外周線** をONにします。コンポーネントがまだない場合は、ペイントウィンドウの部位一覧で対象をONにすると追加されます。
3. マテリアルの **Use Hull Outline** をONにし、**Width** で線幅を調整します。

メッシュの開いた縁を面に沿って広げ、片面の板に外周線を作ります。曲面では、縁に沿う線に加えて、カメラから見たシルエットにも線を描きます。`face.unity` の `Sphere002` では、前髪の縁と頭頂部から左右へ続く髪の輪郭を両方描画します。

板の表裏に外周線を表示する場合は、マテリアルの **Surface Mode → Cutout Both Sides** を選びます。顔サンプルの生成済み髪・眉毛マテリアルは、元の Surface Mode が Opaque の場合、次回のサンプル作成時にこの設定へ切り替わります。

## 眉毛の輪郭線を髪の手前に出す

1. 髪のInspectorで **SP Toon Outline Painter → 髪の遮蔽マスク** をONにします。
2. 眉毛のInspectorで **SP Toon Outline Painter → 輪郭線を髪の手前に** をONにします。
3. 顔本体のInspectorで **SP Toon Outline Painter → 顔で眉毛の線を遮る** をONにします。
4. 眉毛マテリアルの **Use Hull Outline** をONにし、**Width** と **Hull Outline Color** を調整します。

髪が実際に表示されている範囲にだけ眉毛の外周線を重ねます。眉毛の塗りは通常の深度で描画されます。顔が眉毛より手前にある箇所では輪郭線も隠れるため、背面から顔越しに線が透けることを防げます。`face.unity` では髪が `Sphere002`、眉毛が `Cylinder001` と `Cylinder002` です。いずれも設定済みです。

### 別プロジェクトで使う場合のURP設定

髪と眉毛の前後関係、および曲面の片面外周線には、カメラが使うURP Renderer Dataに次の **Render Objects** が必要です。**Create Face Sample** を実行すると必要なRenderer Featureを順番に設定します。手動で追加する場合は、表の順にすべて **After Rendering Skybox** へ追加します。同じイベント内ではRenderer Feature一覧の順で実行します。不透明キューのマテリアルを使い、各Featureの **Pass Names** に下表のタグを1つ指定します。**Layer Mask** に対象のレイヤーを含めます。Override Modeは **None** にし、深度・ステンシルはシェーダー側の設定を使用します。描画順は表の上から下です。

| 描画順 | Pass Names | 役割 |
|---|---|---|
| After Rendering Skybox | `SPToonHairMask` | 見えている髪の範囲を記録 |
| 同イベント内で髪マスクの後 | `SPToonPlateSilhouette` | 片面曲面のシルエット線 |
| 同イベント内で髪マスクの後 | `SPToonHairBoundary` | 髪の内側を除いて前髪の縁を描画 |
| 上記の後 | `SPToonBrowInterior` | 眉毛の中央をマスク |
| 眉毛の中央マスクの後 | `SPToonClearHairDepth` | 髪マスク内の深度をいったん初期化 |
| 深度初期化の後 | `SPToonFaceOccluderDepth` | 顔の深度を書き込む |
| 顔の深度を書き込んだ後 | `SPToonOverHair` | 顔に遮られない眉毛の外周線を髪に重ねる |
| 眉毛の描画後 | `SPToonRestoreHairDepth` | 髪の深度を復元 |

## 保存と制限

元メッシュと元の頂点カラーは変更しません。補正はコンポーネントに保存し、頂点単位のデータテクスチャとして既存Hull Outlineの頂点処理へ渡します。

メッシュのRead/Writeが必要です。確認用MeetMatは有効化済みです。Static Batchingは対象の初期設定時に外します。頂点の少ない場所では細かい描き分けに限界があります。頂点数・頂点順を変更する再インポートへの自動対応はありません。消去のソフトな境界にはディザを使います。
