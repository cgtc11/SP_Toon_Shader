XRay Outline

導入と基本操作 輪郭と塗りの使い分け 設定項目 困ったとき

導入と基本操作

  1. HologramXRayOutline.shader、HologramXRayMask.shaderとEditor内のHologramSetupTool.csを導入します。
  2. 本体Materialを割り当てた対象をHierarchyで選択します。
  3. Tools > Hologram URP > Xray > Add XRay To Selected Objectを実行します。選択したオブジェクトと子のRendererが対象です。
  4. 本体 → XRay Mask → XRay Outlineの順に追加されます。手動でも同じ順でMaterials末尾に追加してください。
  5. 壁の後ろへ移動して、Outline Materialの色とOpacityを調整します。

輪郭と塗りの使い分け

Show Flat Fill When OccludedをOFFにすると輪郭中心、Show Outline When OccludedをOFFにすると塗り中心になります。両方OFFなら表示しません。Pulse Amount＝0で明滅を止めます。

XRay MaskとStencil Refを揃えてください。本体の見た目は元のMaterialが担当します。壁などが深度を書いていることが必要で、深度を書かない半透明の壁では期待どおりに出ない場合があります。

複数サブメッシュのRendererでは末尾に追加したMaterialが最後のサブメッシュにだけ作用するため、全身へ適用できない場合があります。共有Stencil Refは複数対象間でも干渉し得ます。Maskだけで完全な自己遮蔽制御を保証する方式ではありません。

困ったとき

  • ピンクになる：URPプロジェクトか確認し、ConsoleのShaderエラーを解消します。
  • Inspectorが期待と違う：必要なGUIスクリプトをEditorフォルダーへ配置し、C#エラーと同名クラスの重複を確認します。
  • フェードが前後にかかる：モデルのローカル軸を確認し、上下に合う軸を選びます。Zが必ず上下ではありません。
  • にじみが出ない：Bloom、Camera Post Processing、HDR、Volume Layer Maskを確認します。

XRay Mask

導入と役割 注意点 設定項目 困ったとき

導入と役割

Shader名はDiGiMonkey/XRay Mask。画面へ色を描かず、深度テストを通過した対象部分にステンシルの印を付けます。XRay Outlineは同じ印がある部分への描画を避けます。Mask単体では見た目は変わりません。

  1. 対象の本体Materialを維持します。
  2. Materialsの末尾へXRay Mask、その後XRay Outlineを追加します。
  3. 両方のStencil Refを同じ値（通常1）にします。

Tools > Hologram URP > Xray > Add XRay To Selected Objectなら両方を自動追加できます。

注意点

本体や壁の深度、描画順、他のステンシル機能に依存します。通常の本体Materialの代わりには使いません。不要な場合はRemove XRay From Selected ObjectsでMaskとOutlineを外せます。

XRay Outlineの説明に、複数サブメッシュや壁の深度に関する注意点を掲載しています。

設定項目

範囲と初期値は現行Shaderから取得しています。GUIの表示名が異なる場合はコード名で対応できます。

Xray Tools

HologramSetupTool.csをEditorフォルダーへ配置し、Tools > Hologram URP > Xrayから実行します。

メニュー動作
Xray > Create XRay Outline Demo Objects壁と奥のCapsuleでXRayを試すデモを作成。
Xray > Add XRay To Selected Object選択オブジェクトと子RendererへMask→Outlineを追加。本体Materialを維持。既にある同じMaterialは重複追加しません。
Xray > Remove XRay From Selected Objects選択オブジェクトと子Rendererから、XRay Mask／Outline Shaderを使うMaterialを除去。本体は保持。

生成先はAssets/HologramURP/Materials。Create MaterialsでMaskとOutlineも作成できます。

現在の同梱ソースに基づく説明書。Inspectorの項目名は英語、説明は日本語。
