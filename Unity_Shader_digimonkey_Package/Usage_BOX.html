URP Lit Box Clip

導入と基本操作

  1. URPLit_BoxClip_v07.shaderを導入し、DiGiMonkey/URPLit_BoxClip_PerfectのMaterialを対象へ割り当てます。
  2. URPLit_BoxMaskController_v02.csを導入し、URPLit_BoxMaskController_v02をマスク用GameObjectへアタッチします。ファイル名とクラス名は一致しているため、変更は不要です。
  3. マスクのTransformで位置・回転・Scaleを調整します。ローカル−0.5～＋0.5の立方体が切り抜き範囲です。
  4. 対象MaterialのEnable Box CutをONにします。
  5. Fade WidthとFade Toward Insideで境界を調整します。

切り抜きと質感

ボックス内を非表示にして、外側を残す方式です。境界は4×4ディザーで薄く見せます。断面を埋める機能はありません。マスクGameObjectのMeshRendererは不要で、見えているCubeを使う場合はRendererをOFFにできます。

Metallic (R) Smoothness (A)のマップをONにすると、金属度はRを直接使い、滑らかさはA×Smoothness Scaleです。Normal MapとEmissionもスイッチをONにして使います。

Albedo / Transparency (RGBA)という名前ですが、現行コードではBaseのアルファによる半透明表示を行いません。通常の半透明ShaderのようなOpacity設定はありません。

切り抜きのグローバル行列はURPLit_BoxMaskController_v02が毎フレーム設定します。複数のControllerを同時に置くと最後に更新した1つが全対象へ作用します。ゼロScaleは使用しないでください。

困ったとき

  • ピンクになる：URPプロジェクトか確認し、ConsoleのShaderエラーを解消します。
  • Inspectorが期待と違う：必要なGUIスクリプトをEditorフォルダーへ配置し、C#エラーと同名クラスの重複を確認します。
  • フェードが前後にかかる：モデルのローカル軸を確認し、上下に合う軸を選びます。Zが必ず上下ではありません。
  • にじみが出ない：Bloom、Camera Post Processing、HDR、Volume Layer Maskを確認します。

URPLit_BoxMaskController_v02

導入と使い方 動作と注意点 調整項目 困ったとき

導入と使い方

  1. URPLit_BoxMaskController_v02.csを導入します。クラス名もURPLit_BoxMaskController_v02で一致しているため、ファイル名の変更は不要です。
  2. マスク用GameObjectへURPLit_BoxMaskController_v02をアタッチします。専用の公開パラメーターはありません。
  3. Transform Position＝中心、Rotation＝向き、Scale＝各辺の大きさとして調整します。
  4. 対象MaterialをURP Lit Box Clipにし、Enable Box CutをONにします。

動作と注意点

UpdateでTransformのworldToLocalMatrixをグローバルShader変数_BoxWorldToLocalへ送ります。Editor上でも動作します。Renderer単位へ別々のボックスを指定する機能はありません。

同時に有効なControllerは1つにしてください。複数なら最後の更新が上書きします。Scaleの0は避けてください。GameObjectを無効化しても、このスクリプトは行列をリセットしません。切り抜きを確実に止めるには対象MaterialのEnable Box CutをOFFにします。

Cubeで位置を確認する場合、見た目のCubeのMeshRendererはOFFにできます。コライダーは切り抜きに不要です。Shaderによる切り抜きは見た目だけで、MeshやColliderは変更しません。

調整項目

項目役割
Transform / Positionマスクボックスの中心位置。
Transform / Rotationマスクボックスの方向。
Transform / Scale立方体の各辺の長さ。1,1,1ならローカル単位の1辺1。
Material / Enable Box Cut切り抜き対象をMaterial単位で選択。

困ったとき

  • ピンクになる：URPプロジェクトか確認し、ConsoleのShaderエラーを解消します。
  • Inspectorが期待と違う：必要なGUIスクリプトをEditorフォルダーへ配置し、C#エラーと同名クラスの重複を確認します。
  • フェードが前後にかかる：モデルのローカル軸を確認し、上下に合う軸を選びます。Zが必ず上下ではありません。
  • にじみが出ない：Bloom、Camera Post Processing、HDR、Volume Layer Maskを確認します。
